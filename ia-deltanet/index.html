Abstract

Transformers excel at sequence modeling through attention, but their quadratic compute and growing key-value cache make them costly for long-range streaming tasks. Linear attention variants, such as DeltaNet, address this by reformulating attention as a recurrent memory equipped with an error-corrective update rule. However, we show that DeltaNet’s update rule induces unintended interference on past-key responses, as the correction signal leaks into every past key that is not orthogonal to the current one.

We propose Interference-Aware DeltaNet (IA-DeltaNet), which generalizes the delta rule by decoupling the key used for error evaluation from the direction along which the memory is updated. We formulate the choice of write direction as a constrained quadratic program that minimizes the total squared interference on past-key responses while exactly preserving DeltaNet’s current-key correction, and derive its closed-form solution as a preconditioned key obtained from the inverse uncentered covariance of past keys. To ensure scalability, we introduce a diagonal approximation of the past-key covariance, preserving the per-step efficiency and chunk-parallelizability of the original architecture.

On multi-query associative recall, interference-aware writing improves retention under high associative load. It also improves over recurrent-memory baselines as a bounded memory in a streaming VideoLLM, and substantially mitigates DeltaNet’s degradation under prolonged recurrent-state propagation in language modeling. These results indicate that explicitly accounting for past-key geometry offers an effective design principle for associative memory in linear-attention architectures.

Interference-Aware Memory Writing

IA-DeltaNet changes the direction of a memory write to disturb past associations less, while keeping the same correction at the current key.

Interference

A write along w disturbs past responses according to its overlap with previous keys kj. We measure this as the sum of squared overlaps:

ℐt(w)=∑j<t(w⊤kj)2=w⊤Σt−1w

Σt−1 is the accumulated uncentered covariance of past keys.

Constrained optimization

Choose the write direction with the least interference, subject to preserving DeltaNet’s correction at the current unit-norm key kt:

ut=arg minwℐt(w)subject tow⊤kt=1

Closed-form solution

ut=Σt−1−1ktkt⊤Σt−1−1kt

The inverse covariance downweights directions already occupied by past keys. The denominator normalizes the write direction so that the current-key correction stays unchanged.

In practice, a diagonal covariance approximation retains DeltaNet’s per-step efficiency and chunk-parallel computation.

Associative Recall

On multi-query associative recall (MQAR), the benefit grows as more key–value associations must fit into the recurrent state. At the highest evaluated load for width 128, IA-DeltaNet improves mean accuracy from 81.7% to 95.5%; the exact variant reaches 97.5%.

Recall from streaming video

In VNBench, the memory processes the entire visual stream, while the LLM sees only the last W frame readouts. IA-DeltaNet outperforms DeltaNet and Gated DeltaNet at every evaluated window size, and comes within 3.5 points of the full-KV attention reference at W = 32.

Long-Document Language Modeling

We train on a 2K-token context and evaluate on PG-19 documents of up to 128K tokens, carrying recurrent states across consecutive chunks within each document.

DeltaNet and IA-DeltaNet start with similar perplexity, but diverge as the state is propagated. At 64–128K tokens, perplexity reaches 90.84 for DeltaNet and 25.51 for IA-DeltaNet.

Gated DeltaNet remains the most stable on this task. Forgetting and interference-aware writing address different parts of the update and can be combined.

Understanding the Memory Writes

Direct measurements connect the improved retention to lower write interference. The diagonal approximation closely follows the exact solution when the covariance is diagonal; rotating the covariance exposes the limits of the approximation.
