Abstract

Transformers excel at sequence modeling through attention, but their quadratic compute and growing key-value cache make them costly for long-range streaming tasks. Linear attention variants, such as DeltaNet, address this by reformulating attention as a recurrent memory equipped with an error-corrective update rule. However, we show that DeltaNet's update rule induces unintended interference on past-key responses, as the correction signal leaks into every past key that is not orthogonal to the current one.

We propose Interference-Aware DeltaNet (IA-DeltaNet), which generalizes the delta rule by decoupling the key used for error evaluation from the direction along which the memory is updated. We formulate the choice of write direction as a constrained quadratic program that minimizes the total squared interference on past-key responses while exactly preserving DeltaNet's current-key correction, and derive its closed-form solution as a preconditioned key obtained from the inverse uncentered covariance of past keys. To ensure scalability, we further introduce a diagonal approximation of the past-key covariance, preserving the per-step efficiency and chunk-parallelizability of the original architecture.

When integrated as a memory module in a VideoLLM, IA-DeltaNet consistently outperforms baselines on streaming video understanding under equivalent bounded memory budgets, with further analyses offering insights into its memory dynamics and computational efficiency. Collectively, these results indicate that explicitly accounting for past-key geometry is essential for designing associative memory in linear-attention architectures.

Past-Key Interference in DeltaNet

DeltaNet replaces additive accumulation with an error-corrective rank-one update,

\[\bm{S}_t = \bm{S}_{t-1} - \beta_t\,\bm{e}_t\,\bm{k}_t^\top, \qquad \bm{e}_t = \bm{S}_{t-1}\bm{k}_t - \bm{v}_t.\]

By writing the correction along $\bm{k}_t$, DeltaNet successfully steers the response at the current key toward $\bm{v}_t$. But applying the same update to a past key $\bm{k}_j$ ($j

\[\bm{S}_t \bm{k}_j = \bm{S}_{t-1}\bm{k}_j - \beta_t\,\bm{e}_t\,(\bm{k}_t^\top\bm{k}_j),\]

so the correction signal leaks into every past key that is not orthogonal to $\bm{k}_t$. In a $d_k$-dimensional space at most $d_k$ directions can be mutually orthogonal, so as the stream progresses, this interference accumulates and degrades stored associations. The root cause is that $\bm{k}_t$ plays two conflicting roles simultaneously: read address for evaluating prediction error and write direction for updating memory.

Interference-Aware DeltaNet

IA-DeltaNet keeps $\bm{k}_t$ as the read address but introduces a separate write direction $\bm{u}_t$:

\[\bm{S}_t = \bm{S}_{t-1} - \beta_t\,\bm{e}_t\,\bm{u}_t^\top.\]

Constrained quadratic program.

We choose $\bm{u}_t$ to minimize total squared past-key interference while preserving the exact current-key correction of DeltaNet ($\bm{u}_t^\top\bm{k}_t = 1$):

\[\bm{u}_t = \arg\min_{\hat{\bm{u}}_t}\; \hat{\bm{u}}_t^\top \bm{\Sigma}_{t-1}\,\hat{\bm{u}}_t \quad \text{s.t.} \quad \hat{\bm{u}}_t^\top \bm{k}_t = 1,\]

where $\bm{\Sigma}_{t-1} = \sum_{j

\[\bm{u}_t = \frac{\bm{\Sigma}_{t-1}^{-1}\bm{k}_t}{\bm{k}_t^\top\bm{\Sigma}_{t-1}^{-1}\bm{k}_t}.\]

$\bm{\Sigma}_{t-1}^{-1}$ acts as a whitening transform that downweights directions already heavily occupied by past keys, and the denominator renormalizes to satisfy the correction constraint. Under isotropic past keys ($\bm{\Sigma}_{t-1}\propto\bm{I}$) this reduces to $\bm{u}_t=\bm{k}_t$, recovering DeltaNet exactly.

Guaranteed interference reduction.

The matrix-form Cauchy–Schwarz inequality $(\bm{k}_t^\top\bm{\Sigma}_{t-1}\bm{k}_t)(\bm{k}_t^\top\bm{\Sigma}_{t-1}^{-1}\bm{k}_t) \geq 1$ implies $\mathcal{I}_t(\bm{u}_t) \leq \mathcal{I}_t(\bm{k}_t)$ for any past-key geometry, with equality only when $\bm{k}_t$ aligns with an eigenvector of $\bm{\Sigma}_{t-1}$.

Diagonal approximation for $O(d_k)$ overhead.

Maintaining a full $\bm{\Sigma}_{t-1}^{-1}$ costs $O(d_k^2)$ per step even with Sherman–Morrison updates. We approximate $\bm{\Sigma}_{t-1}\approx \operatorname{diag}(\bm{d}_{t-1})$ where $\bm{d}_t = \bm{d}_{t-1} + \bm{k}_t\odot\bm{k}_t$ is an element-wise prefix sum of squared keys. The resulting write direction

\[\bm{u}_t = \frac{\bm{D}_{t-1}^{-1}\bm{k}_t}{\bm{k}_t^\top\bm{D}_{t-1}^{-1}\bm{k}_t}\]

adds only $O(d_k)$ overhead per step, preserves DeltaNet's $O(d_v d_k)$ rank-one update, and remains chunk-parallelizable via associative scans because $\bm{d}_t$ is a simple prefix sum.

Streaming Video Understanding

We integrate IA-DeltaNet as a fixed-size recurrent memory module on top of the Qwen3.5-4B vision aligner, processing visual tokens in temporal order. The LLM only sees readouts from the last $W$ frames; earlier frames must propagate through the recurrent state. IA-DeltaNet is the best bounded-memory model across all $W$, and the gain is largest in the small-$W$ regime where the model relies most heavily on the state.

Analysis

(a) Synthetic past-key interference. Across anisotropies and eigenspace rotations, even the diagonal IA-DeltaNet stays below DeltaNet—suppressing anisotropic interference outweighs diagonal approximation error.

(b) Interference on real video keys. On Video-MME (medium subset), IA-DeltaNet yields lower write-direction interference $\mathcal{I}_t(\bm{w})$ than DeltaNet across timesteps, mirroring the synthetic trend.

(c) Needle recall (VNBench). IA-DeltaNet consistently retrieves more needle-frame information than DeltaNet/GatedDeltaNet, narrowing the gap to the unbounded-memory attention reference.

(d) Efficiency. Time-to-first-token and GPU memory remain stable as the number of frames grows; IA-DeltaNet adds only marginal overhead over DeltaNet, while attention OOMs on long inputs.
